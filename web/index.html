What this demonstrates

The model, pretrained policies, native controller and scene come from the public Jumper projects. ClawMetry filters the task requests in this page and shows measured simulator events. A denied request was not forwarded by this page. This does not guarantee containment or physical safety.

The seated person is a static scene proxy. The task cup is empty; the cleanup object is a rigid paper-ball proxy. Task objects move through simulated contacts. No human detection, liquid handling or physical robot performance is established. The native Jumper policy provides support. Object tasks use a scripted left-claw joint controller in this scene; contact and gravity move the free objects. ClawMetry records task permission and measured results.
